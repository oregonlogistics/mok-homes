# Mok Homes website starter

A responsive, single-page interior design portfolio template with project stories, a filterable room gallery, a shop-the-look concept, an about section, and an inquiry form.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Before publishing

- Replace the sample project names, descriptions, and Unsplash image URLs with your own project content and photography.
- Replace the sample About copy with your bio, service area, and design approach.
- Add real product links to the shop-the-look list if you plan to sell or recommend products.
- Connect the inquiry form to your preferred email service or CRM. The current form validates the fields but does not transmit submissions.
- Update the page title, description, and business contact information.

The sample room photography is served from Unsplash and is for layout demonstration; confirm image licensing and usage terms for your final site.
